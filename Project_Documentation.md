## Project Overview

We are building a Game Library API which will allow users to view all available games, log in securely,
and create a personalized watchlist based on their preferences.

The main idea of this project is to make it easy for users to explore games and save the ones they are
interested in. Instead of searching again, users can simply add games to their watchlist and access them anytime.

## Key Features

### View All Games
Users can see a list of all available games in the system.

### User Login
Users can sign up and log in securely using Firebase Authentication, which will have information about their
perferences, userID and more.

### Create Watchlist
Users can add games to their personal watchlist based on their preferences and view or manage them anytime.

## Main Resources

### Games
Stores game details like title, genre, platform, and rating.

### Users
Handles authentication and user data.

### Watchlist
Stores the list of games saved by each user.

## Project Goal
The goal of this project is to build a secure and well-structured back-end API by:

- Following proper backend architecture (routes, controllers, services, repository)  
- Implementing authentication and authorization  
- Adding validation and error handling  
- Writing unit tests using Jest  
- Documenting APIs using Swagger
